# TechPanda NeonPlan 3D 4.0.2.1

Downstream customization based on the official NeonPlan 3D `v4.0.2` release (upstream commit `503bcb368ba06cd8e31e2df6da1a1000158cf275`). The four-part version denotes upstream `4.0.2`, TechPanda revision `1`; the release uses tag `v4.0.2.1` and preserves upstream tags and licensing.

## Included

- Adds TechPanda's public Ed25519 key to the trusted furniture registry, restricted to signed `studio.*` furniture-only packs. All official public keys and signature checks remain intact.
- Adds the native Rectangular Water Tank furniture definition and tooling source. Import its separately signed `techpanda-water-tanks.fp3dpack` asset after upgrading the integration.
- Uses only NeonPlan's existing box/cylinder geometry, furniture sizing/elevation controls, and optional level sensor binding. No upstream renderer, editor, backend schema, or geometry engine was changed.
- HACS integration ZIP is based on the official `v4.0.2` release asset, with the TechPanda trusted-key registry, downstream manifest version, and two frontend bundles regenerated to report that matching version. Its files are at ZIP root as required by HACS `zip_release` extraction.

The Home Assistant deployment remains gated on HACS source verification, a verified integration-only backup, explicit approval to write remote files, and separate approval to restart Home Assistant.
